# 고정 메뉴 사진

사전에 준비한 메뉴 사진을 이 디렉터리에 저장합니다. 실제 메뉴 사진 원본은 아직 추가하지 않았습니다.

- 가급적 용량을 줄인 WebP 파일을 사용합니다(권장: 정사각형 800x800 내외).
- 소문자 영문/숫자/하이픈으로 파일명을 짓습니다. 예: `classic-burger.webp`
- Menu DB의 `menus.image_url`에는 `/images/menus/classic-burger.webp`처럼 **사이트 루트 상대 경로**를 저장합니다. 실제 파일이 없는 메뉴에는 NULL을 사용합니다.
- 이 경로는 프론트엔드가 정적 파일로 제공하며, `/api/`의 Menu API 요청과 구분됩니다.
- 기존 파일명을 변경하면 해당 DB의 경로도 변경해야 하므로, 이미 참조 중인 파일은 함부로 이름을 바꾸지 않습니다.
- 새 사진을 추가하거나 변경하면 프론트엔드 이미지 빌드/배포가 필요합니다.
- 사진은 사용 권한과 출처를 확인한 뒤 Git에 등록합니다. 외부 URL 의존 및 저작권 불명 이미지 사용을 피합니다.

관리자 파일 업로드, 사용자 프로필 업로드 및 Object Storage는 **추후 기능**입니다.
