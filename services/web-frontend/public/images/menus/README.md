# 고정 메뉴 사진

현재 이 디렉터리에는 아래 WebP 메뉴 이미지 8개가 추가되어 있습니다. 파일명과 메뉴 이름의 연결은 `src/menuImages.js`를 따릅니다.

| 파일명                       | 메뉴               | 원본 출처·제작 방식 | 사용권·라이선스 |
| ---------------------------- | ------------------ | ------------------- | --------------- |
| `classic-burger.webp`        | 클래식 버거        | 미확인              | 미확인          |
| `double-cheese-burger.webp`  | 더블 치즈 버거     | 미확인              | 미확인          |
| `crispy-chicken-burger.webp` | 크리스피 치킨 버거 | 미확인              | 미확인          |
| `mushroom-burger.webp`       | 머시룸 버거        | 미확인              | 미확인          |
| `french-fries.webp`          | 프렌치 프라이      | 미확인              | 미확인          |
| `onion-rings.webp`           | 어니언 링          | 미확인              | 미확인          |
| `cola.webp`                  | 콜라               | 미확인              | 미확인          |
| `classic-burger-set.webp`    | 클래식 버거 세트   | 미확인              | 미확인          |

확인 가능한 추가 이력은 [#319 최초 추가 커밋 `4933775`](https://github.com/ktcloud-cloudnative-2026/team02-5xx/commit/49337750a58665fe72f685fb488c7ec8a7c134eb)입니다. 이 이력은 저장소에 파일이 추가된 근거이며, 원본 제작자나 사용 허락의 증빙은 아닙니다.

확인한 저장소 문서에는 원본 URL·제작자·생성 도구·라이선스·사용 허락 증빙이 기록되어 있지 않습니다. 8개 파일의 WebP RIFF 청크에서도 EXIF/XMP 출처·권리 메타데이터를 확인하지 못했습니다. 따라서 사용자 제공 이미지, 생성 이미지, 외부 이미지 중 어느 유형인지 단정하지 않습니다. 원본 제공자와 출처·사용권 증빙을 확인한 뒤 이 표를 갱신해야 하며, 파일이 존재한다는 이유로 권리 확인이 완료된 것으로 간주하지 않습니다.

- 가급적 용량을 줄인 WebP 파일을 사용합니다(권장: 정사각형 800x800 내외).
- 소문자 영문/숫자/하이픈으로 파일명을 짓습니다. 예: `classic-burger.webp`
- Menu DB의 `menus.image_url`에는 `/images/menus/classic-burger.webp`처럼 **사이트 루트 상대 경로**를 저장합니다. 실제 파일이 없는 메뉴에는 NULL을 사용합니다.
- 이 경로는 프론트엔드가 정적 파일로 제공하며, `/api/`의 Menu API 요청과 구분됩니다.
- 기존 파일명을 변경하면 해당 DB의 경로도 변경해야 하므로, 이미 참조 중인 파일은 함부로 이름을 바꾸지 않습니다.
- 새 사진을 추가하거나 변경하면 프론트엔드 이미지 빌드/배포가 필요합니다.
- 사진은 사용 권한과 출처를 확인한 뒤 Git에 등록합니다. 외부 URL 의존 및 저작권 불명 이미지 사용을 피합니다.

관리자 파일 업로드, 사용자 프로필 업로드 및 Object Storage는 **추후 기능**입니다.
